مرحباً، أنا أحمد علي

مطور واجهات أمامية ومصمم مواقع ويب. أساعد الشركات والأفراد في بناء حضور رقمي مميز.

من أنا

أنا أحمد علي، مطور مواقع ويب بخبرة 3 سنوات في تصميم وتطوير الواجهات الأمامية.

أعمل على تحويل الأفكار إلى مواقع إلكترونية عملية، سريعة، وسهلة الاستخدام. أركز على تقديم تجربة مستخدم ممتازة مع كود نظيف ومنظم.

حصلت على شهادة في علوم الحاسوب وأستمر في تطوير مهاراتي باستمرار لمواكبة أحدث التقنيات.

الخدمات التي أقدمها

تصميم مواقع متجاوبة

أصمم مواقع تعمل بشكل مثالي على جميع الأجهزة من حواسيب مكتبية إلى هواتف محمولة.

تطوير واجهات المستخدم

أطور واجهات تفاعلية باستخدام HTML و CSS و JavaScript لتحسين تجربة المستخدم.

تحسين أداء المواقع

أحلل وأحسن أداء المواقع لزيادة سرعة التحميل وتحسين ترتيب البحث.

منهجية العمل

  • المرحلة الأولى: تحليل المتطلبات وفهم احتياجات العميل
  • المرحلة الثانية: تصميم واجهات وإطارات أولية
  • المرحلة الثالثة: تطوير وبرمجة الموقع
  • المرحلة الرابعة: اختبار وتسليم المشروع النهائي

المهارات التقنية

  • HTML5 / CSS3
  • JavaScript (ES6+)
  • React.js
  • Bootstrap / Tailwind CSS
  • Git / GitHub
